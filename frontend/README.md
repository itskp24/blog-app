# Blog Frontend

A premium, journal-style blog built with **Next.js**, featuring pixel-perfect design, dynamic SEO, and shimmering skeleton loaders.

## 🚀 Getting Started

> [!IMPORTANT]
> Ensure the **Backend** is set up and running before starting the frontend.

### 1. Installation
Install the project dependencies:
```bash
npm install
```

### 2. Environment Setup
Create a `.env` file in the root directory (if not present) and ensure it contains the correct API URL:
```env
NEXT_PUBLIC_API_URL=http://localhost:5000
```

### 3. Development Mode
Run the development server:
```bash
npm run dev
```

### 4. Production Build
To create an optimized production build:
```bash
npm run build
npm start
```
